1. Envie o extrato do INSS e informe a idade

O sistema lê automaticamente o PDF de histórico de empréstimo consignado e extrai os dados do benefício, da margem e dos contratos ativos. O único dado que o extrato não traz é a idade do cliente — por isso ela é digitada manualmente aqui.

Clique para selecionar o PDF
ou arraste o arquivo até aqui
Único campo de preenchimento manual. Usado para calcular o prazo máximo permitido em cada banco.

2. Confira os dados extraídos

Revise e edite antes de simular. Estes dados alimentam os três fluxos de simulação.

Margem (por modalidade)

Contratos ativos e suspensos

3. Escolha o fluxo de simulação

Margem livre

Usa a margem disponível informada no extrato para liberar um novo crédito, sem envolver os contratos ativos.

Portabilidade pura

Migra o saldo devedor de cada contrato ativo para o banco de destino, buscando taxa e parcela melhores.

Portabilidade + Refinanciamento

Porta o saldo devedor e libera um troco adicional no mesmo banco de destino.
